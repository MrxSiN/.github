# Contributing

1. Read the repository's `AGENTS.md`. Its rules apply to people and coding agents alike.
2. Branch from the default branch, keep one change per pull request, and say what you actually ran (EXECUTED, MEASURED, NOT RUN or BLOCKED). Emulator runs are not device runs.
3. If the fix belongs in a toolchain (XAX, BBC or XAX-MCP), fix it there first. Don't patch around it in a consumer; see [the ecosystem policy](ECOSYSTEM_POLICY.md).
4. Security problems go through private reporting ([SECURITY.md](SECURITY.md)), not issues.
